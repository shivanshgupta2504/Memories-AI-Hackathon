# Memories-AI-Hackathon
This Repository contains the Example Usage of Memories.ai API and the Hackathon Project

## Steps to get Started
- Clone the Repo
```shell
git clone https://github.com/shivanshgupta2504/Memories-AI-Hackathon.git
```
- Create a `.env` file and add your API key in. Example
```python
MEMORIES_AI_API_KEY="<API_KEY>"
```
- Enjoy and Work 🥳
